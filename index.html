  1. Save the file into Steam/steamapps/common/Counter-Strike Global Offensive/game/csgo/cfg/. Put practice.cfg in the same folder.
    2. 
            
  2. In Steam, right-click Counter-Strike 2, choose Properties, and add +exec autoexec to Launch options.
